# 文本词频词性分析

## Overview

分析文本的词频统计和词性（Part-of-Speech）分布，支持中英文文本，输出词频排行和词性分类结果。

## 使用场景

- 分析文章或文档中的高频词汇
- 统计文本中各类词性（名词、动词、形容词等）的分布
- 提取文本关键词，辅助内容摘要或标签生成
- 对比多篇文本的词汇使用特征
- 为自然语言处理任务提供基础统计信息

## 工作流程

1. 接收用户提供的文本内容或文本文件路径
2. 执行 `scripts/main.py` 脚本，传入文本及相关参数
3. 脚本对文本进行分词和词性标注
4. 统计词频并计算词性分布
5. 返回结构化的分析结果，包含词频排行和词性占比

## 输入/输出

- 输入：
  - `text`：待分析的文本字符串（必填）
  - `lang`：文本语言，可选 `zh`（中文）或 `en`（英文），默认 `zh`
  - `top_n`：返回词频最高的前 N 个词，默认 20
- 输出：
  - `word_frequency`：词频排行列表，每项包含词语和出现次数
  - `pos_distribution`：词性分布统计，每项包含词性标签、数量和占比
  - `total_words`：总词数（去重后）

## 脚本说明

`scripts/main.py` 是核心分析脚本，通过命令行参数接收配置：

```
python scripts/main.py --text "文本内容" --lang zh --top_n 20
```

或从文件读取：

```
python scripts/main.py --file input.txt --lang en --top_n 30
```

脚本依赖 `jieba`（中文分词）和 `nltk`（英文分词及词性标注），首次使用前需安装：

```
pip install jieba nltk
```

## 注意事项

- 中文文本使用 jieba 进行分词和词性标注，英文文本使用 NLTK
- 脚本会自动过滤标点符号和停用词
- 词性标签遵循对应语言的标准标注集（中文使用 jieba 词性标签，英文使用 Penn Treebank 标签）
- 对于大文本（超过 10 万字），建议通过文件路径传入以避免命令行参数过长
