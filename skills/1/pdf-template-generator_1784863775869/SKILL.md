# PDF模板生成器

## Overview

根据自然语言需求描述自动生成PDF文档模板，支持多种布局样式和表单元素，输出可直接使用的PDF文件。

## 使用场景

- 创建包含表单字段的可填写PDF模板（如申请表、调查问卷）
- 生成带有页眉页脚、表格和图表占位符的报告布局
- 设计发票、收据、合同等商务文档模板
- 制作带有固定布局的证书、信函模板

## 工作流程

1. 接收用户对PDF模板的需求描述（布局、字段、样式等）
2. 解析需求，确定模板类型和结构
3. 调用 `scripts/main.py` 生成PDF模板文件
4. 输出生成的PDF文件路径和模板说明

## 输入/输出

- 输入：PDF模板的需求描述，包括：
  - 模板类型（表单、报告、发票等）
  - 页面布局要求（页边距、列数、页眉页脚等）
  - 表单字段定义（字段名称、类型、位置）
  - 样式偏好（字体、颜色、Logo位置等）
- 输出：生成的PDF模板文件（.pdf）及简要说明

## 脚本说明

`scripts/main.py` 是核心生成脚本，负责：
- 解析传入的模板配置参数
- 使用 reportlab 或类似库构建PDF结构
- 渲染表单字段、表格、文本块等元素
- 输出最终PDF文件到指定目录

## 注意事项

- 生成的PDF模板为静态布局文件，不包含动态数据绑定
- 表单字段为占位符形式，实际填充需配合其他工具
- 中文内容需确保系统已安装对应字体
- 复杂表格和图表仅生成占位区域，实际数据需后续填充
