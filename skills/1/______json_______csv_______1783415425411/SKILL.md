# JSON to CSV Converter

## Overview
此技能将结构化的 JSON 数据（无论是文件输入还是内联字符串）高效转换为标准的 CSV 格式，保留键值对作为列头，数组对象作为数据行。

## 使用场景
- 从 API 响应或数据库导出 JSON 数据并转换为 Excel 可读取的 CSV 文件。
- 将嵌套较浅的 JSON 数组扁平化为表格数据进行快速分析。
- 数据迁移任务中，将 JSON 格式的历史数据转换为传统电子表格系统兼容的格式。

## 工作流程
1. **识别输入**：接收 JSON 文件路径或 JSON 字符串作为输入。
2. **解析数据**：使用脚本解析 JSON 内容，提取所有唯一的顶层键作为 CSV 列头。
3. **数据转换**：遍历 JSON 数组中的每个对象，将值映射到对应的列头，处理缺失值（留空）。
4. **生成输出**：将转换后的数据写入 CSV 格式字符串或文件，默认输出到当前目录下的 `output.csv` 或控制台。

## 输入/输出
- **输入**：
  - `input`: JSON 文件路径（如 `data.json`）或 JSON 字符串。
  - `output`: (可选) 输出文件名，默认为 `output.csv`。
- **输出**：
  - 一个标准的 CSV 文件，包含由 JSON 键生成的表头行和对应的数据行。
  - 如果未指定输出文件，CSV 内容将打印到标准输出。

## 脚本说明
该技能包含一个核心脚本 `scripts/main.js`。
- **用途**：执行 JSON 解析、键提取、数据映射和 CSV 序列化逻辑。
- **使用方法**：在技能运行时，脚本会自动读取提供的输入参数，处理数据并生成结果。脚本内部使用了标准的 Node.js `fs` 模块进行文件操作，无需额外安装第三方库（假设运行环境支持）。

## 注意事项
- **嵌套结构限制**：当前脚本主要处理扁平的 JSON 对象数组。如果 JSON 包含深层嵌套对象或数组，这些复杂结构将被序列化为 JSON 字符串形式存储在该列中，或导致解析错误（取决于具体实现逻辑）。
- **特殊字符处理**：如果字段值包含逗号、换行符或双引号，脚本会自动添加引号包裹该字段以确保 CSV 格式合规。
- **非数组根节点**：如果根节点是单个对象而非数组，脚本将自动将其视为单行数据进行处理。
